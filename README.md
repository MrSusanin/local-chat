# Локальный чат (ИИ на iPhone)

Чат в стиле ChatGPT, который умеет работать **полностью на вашем iPhone** — без интернета и без аккаунтов — на библиотеке [MLX](https://github.com/ml-explore/mlx-swift-lm) от Apple и небольших открытых моделях (Qwen 2.5, Llama 3.2). А если нужно «поумнее» — прямо в приложении можно подключить облачные ИИ: **OpenAI, Google Gemini и Groq**.

- Экран входа при первом запуске (логин и пароль хранятся только на устройстве).
- Локальная модель скачивается один раз (0,4–1,9 ГБ) и дальше работает без интернета. Есть «супер-модель» Qwen 2.5 3B — заметно умнее остальных.
- Облачные ИИ: OpenAI (GPT‑4o), Google Gemini (2.0/2.5 Flash и Pro), Groq (Llama 3.1/3.3). У каждого провайдера тоже есть «супер-модель».
- Кнопки вложений зависят от выбранной модели: понимает ли она **фото, аудио или PDF** — такие кнопки и появятся над полем ввода.
- Ответы появляются по мере генерации, можно остановить кнопкой.
- Вся история чатов хранится в **Core Data** на устройстве и не отправляется никому, кроме выбранного ИИ.
- Долгое нажатие на сообщение копирует текст; вложения открываются встроенным просмотрщиком.

## Требования

- iPhone с **iOS 17 или новее** (iPhone 13 подходит; 4 ГБ памяти позволяют запускать модели до ~1,5 млрд параметров).
- Свободные 2 ГБ места и Wi‑Fi для первой загрузки локальной модели.
- Для облачных ИИ — API ключ (см. ниже). Для локальной модели ключи не нужны.

## Как собрать (без Mac, бесплатно)

1. Создайте на GitHub **новый публичный репозиторий** (например `local-chat`).
2. Загрузите в него всё содержимое этой папки, **включая скрытую папку `.github`**. Файл `.github/workflows/build.yml` проще всего создать на сайте вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, вставить текст из файла.
3. Откройте вкладку **Actions**. Сборка запустится сама. **Первая сборка идёт 10–25 минут**, потому что компилируется библиотека MLX.
4. После зелёной галочки файл лежит в **Releases**: `https://github.com/ВАШ_ЛОГИН/local-chat/releases/latest/download/LocalChat.ipa`

IPA собирается без подписи. Установите его через AltStore или Sideloadly, как калькулятор.

## Как получить API ключ для облачного ИИ

| Провайдер | Где взять ключ | Что умеет |
|---|---|---|
| OpenAI | [platform.openai.com](https://platform.openai.com) → API keys | GPT‑4o mini (фото), GPT‑4o «СУПЕР» (фото), GPT‑4o audio (фото + аудио) |
| Google Gemini | [aistudio.google.com](https://aistudio.google.com) → Get API key | Flash и Pro: фото, аудио и PDF |
| Groq | [console.groq.com](https://console.groq.com) → API Keys | Llama 3.1 8B и 3.3 70B «СУПЕР», только текст |

Ключ вводится один раз в приложении: меню «⋯» → **Сменить ИИ / модель** → выберите провайдера → вставьте ключ → «Начать чат». Ключ хранится в **связке ключей** устройства и уходит только на серверы выбранного провайдера. Сменить ключ можно там же или в настройках.

## Важные особенности iOS

- Приложению нельзя считать на GPU в фоне, поэтому при сворачивании генерация останавливается. Это ограничение iOS, не баг.
- Бесплатная подпись не даёт включить расширенный лимит памяти, поэтому локальная «супер-модель» 3B может не запуститься на iPhone с 4 ГБ ОЗУ (в приложении есть предупреждение).
- Подпись живёт 7 дней, потом приложение нужно переустановить или продлить через AltStore. Скачанная модель, чаты и API ключи при этом сохраняются, если не удалять приложение.
- Для вложений есть лимит 10 МБ на файл: фото сжимаются до ~2048 px автоматически.
- Облачным моделям передаются только последние сообщения диалога (вложения — из последних 4), чтобы запрос не разрастался.

## Файлы

- `Sources/LocalChatApp.swift` — точка входа (проверяет вход в аккаунт)
- `Sources/LoginView.swift`, `Sources/AppSessionStore.swift` — экран входа и локальная «учётная запись»
- `Sources/ContentView.swift` — интерфейс: чат, экран выбора ИИ, настройки, история
- `Sources/ChatViewModel.swift` — состояние чата, генерация (локальная и облачная), сохранение
- `Sources/AIProvider.swift` — список провайдеров и моделей (включая «супер-модели» и их возможности)
- `Sources/AIProviderClient.swift` — клиенты API OpenAI/Groq и Gemini (стриминг, вложения)
- `Sources/Attachments.swift` — вложения: фото, аудио, документы, просмотрщик файлов
- `Sources/CoreDataStack.swift` — хранение чатов в Core Data (+ перенос из старого JSON)
- `Sources/KeychainStore.swift` — API ключи в связке ключей
- `Sources/MessageViews.swift` — разметка сообщений, блоки кода, значки вложений
- `project.yml` — описание проекта для XcodeGen (подключает MLX)
- `.github/workflows/build.yml` — облачная сборка

Сменить или добавить модель: списки в `Sources/AIProvider.swift` (`localModels`, `openAIModels`, `geminiModels`, `groqModels`). Подойдут любые 4-битные модели из [mlx-community](https://huggingface.co/mlx-community) размером до 1,5B (3B — только на устройствах с 6+ ГБ ОЗУ). У модели в списке можно указать `capabilities: [.text, .image, .audio, .document]` — по ним появляются кнопки вложений — и `isSuper: true` для значка «СУПЕР».
