# Локальный чат (ИИ на iPhone)

Чат в стиле ChatGPT, который работает **полностью на вашем iPhone**, без интернета и без аккаунтов. Использует библиотеку [MLX](https://github.com/ml-explore/mlx-swift-lm) от Apple и небольшие открытые модели (Qwen 2.5, Llama 3.2).

- Модель скачивается один раз при первом запуске (0,4–1 ГБ) и дальше хранится в телефоне.
- Ответы появляются по мере генерации, можно остановить кнопкой.
- Долгое нажатие на сообщение копирует текст.
- Меню «⋯»: новый чат, смена модели.

## Требования

- iPhone с **iOS 17 или новее** (iPhone 13 подходит; 4 ГБ памяти позволяют запускать модели до ~1,5 млрд параметров).
- Свободные 2 ГБ места и Wi‑Fi для первой загрузки модели.

## Как собрать (без Mac, бесплатно)

1. Создайте на GitHub **новый публичный репозиторий** (например `local-chat`).
2. Загрузите в него всё содержимое этой папки, **включая скрытую папку `.github`**. Файл `.github/workflows/build.yml` проще всего создать на сайте вручную: **Add file → Create new file**, имя `.github/workflows/build.yml`, вставить текст из файла.
3. Откройте вкладку **Actions**. Сборка запустится сама. **Первая сборка идёт 10–25 минут**, потому что компилируется библиотека MLX.
4. После зелёной галочки файл лежит в **Releases**: `https://github.com/ВАШ_ЛОГИН/local-chat/releases/latest/download/LocalChat.ipa`

IPA собирается без подписи. Установите его через AltStore или Sideloadly, как калькулятор.

## Если сборка упала

Откройте красный шаг в Actions и пришлите последние строки с ошибкой. Чаще всего это мелкая несовместимость версий библиотеки, которая исправляется одной строкой.

## Важные особенности iOS

- Приложению нельзя считать на GPU в фоне, поэтому при сворачивании генерация останавливается. Это ограничение iOS, не баг.
- Бесплатная подпись не даёт включить расширенный лимит памяти, поэтому большие модели (3B и больше) не запустятся.
- Подпись живёт 7 дней, потом приложение нужно переустановить или продлить через AltStore. Скачанная модель при этом сохраняется, если не удалять приложение.

## Файлы

- `Sources/ChatViewModel.swift` — загрузка модели и генерация ответов
- `Sources/ContentView.swift` — интерфейс
- `Sources/LocalChatApp.swift` — точка входа
- `project.yml` — описание проекта для XcodeGen (подключает MLX)
- `.github/workflows/build.yml` — облачная сборка

Сменить или добавить модель: список `models` в начале `ChatViewModel.swift`. Подойдут любые 4-битные модели из [mlx-community](https://huggingface.co/mlx-community) размером до 1,5B.
