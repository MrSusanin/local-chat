# Калькулятор для iPhone (SwiftUI)

Простой калькулятор в стиле iOS: сложение, вычитание, умножение, деление, проценты, смена знака, повтор «=», свайп по экрану стирает последнюю цифру. Без рекламы, без сторонних библиотек. Минимальная версия iOS — 15.

Собирается **бесплатно в облаке GitHub** — Mac и Xcode не нужны.

## Как получить .ipa (без Mac)

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно).
2. Создайте новый репозиторий: **New repository** → имя, например, `calculator` → **Public** (для публичных репозиториев сборки на macOS бесплатны) → **Create**.
3. Загрузите в него все файлы из этой папки (кнопка **Add file → Upload files**). Важно, чтобы папка `.github/workflows/` с файлом `build.yml` тоже попала в репозиторий. Если проводник скрывает папки с точкой, перетащите её отдельно или включите показ скрытых файлов.
4. Откройте вкладку **Actions**. Сборка запустится сама после загрузки (или нажмите **Build IPA → Run workflow**). Она идёт примерно 3–6 минут.
5. Когда появится зелёная галочка:
   - справа на главной странице репозитория в блоке **Releases** будет релиз «Calculator (последняя сборка)» с файлом `Calculator.ipa`;
   - постоянная ссылка на файл: `https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ/releases/latest/download/Calculator.ipa`
   - запасной вариант: в самом запуске во вкладке Actions внизу раздел **Artifacts → Calculator-ipa** (там .ipa лежит внутри zip).

IPA собирается **без подписи** — так и нужно: AltStore подпишет его вашим Apple ID при установке.

## Установка через AltStore

1. Установите AltServer на компьютер (altstore.io) и поставьте AltStore на iPhone по кабелю.
2. Скачайте `Calculator.ipa` на iPhone (в Safari по ссылке выше) и откройте через «Поделиться» → AltStore. Либо в AltStore: вкладка **My Apps** → **+** → выберите файл.
3. Приложение появится на экране. На бесплатном Apple ID оно живёт 7 дней, потом AltStore продлевает подпись автоматически, когда iPhone и компьютер в одной Wi‑Fi сети. Лимит бесплатного аккаунта — 3 приложения одновременно.

## Если есть Mac

```bash
brew install xcodegen
xcodegen generate
open Calculator.xcodeproj
```

Дальше выберите свою команду в **Signing & Capabilities** и запустите на устройстве.

## Что где лежит

- `Sources/CalculatorModel.swift` — вся логика вычислений
- `Sources/ContentView.swift` — интерфейс
- `Sources/CalculatorApp.swift` — точка входа
- `project.yml` — описание проекта для XcodeGen (файл `.xcodeproj` генерируется автоматически)
- `.github/workflows/build.yml` — бесплатная облачная сборка

## Свои настройки

- Название на экране: `CFBundleDisplayName` в `project.yml`
- Идентификатор приложения: `PRODUCT_BUNDLE_IDENTIFIER` в `project.yml`. Если AltStore ругается, что такой ID занят, поменяйте `com.example` на что-то своё.
